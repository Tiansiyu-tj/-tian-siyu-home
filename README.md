## GitHub Pages 部署（推荐）

1. 新建一个仓库（例如 `tian-siyu-home`）
2. 将本目录全部内容推送到仓库
3. 打开仓库 `Settings -> Pages`
4. Source 选择 `GitHub Actions`
5. 已提供 `.github/workflows/pages.yml`（每次 `main` 分支推送后自动发布）

## 访问地址示例

若仓库名为 `tian-siyu-home`，最终地址通常是：
`https://你的用户名.github.io/tian-siyu-home/`
